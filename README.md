# Group Chat Rota

Your staff already posted their availability in the group chat. Paste it: AI turns each "can't do tues after 4" into a quoted constraint you confirm, and a deterministic solver builds a rota that covers every shift within your rest and hours rules.

Built for TestSprite Hackathon Season 4. Work in progress: the full README (live URL, judge path, test suite) lands with the first release.
